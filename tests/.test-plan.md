## Quality bar — Definition of Done for this repo

A repo is only at 100% when ALL of these are true:

1. **100% flow coverage.** Every user-facing flow has at least one Tier 1 test.
2. **Functional-flow tests ≥70% of total.** Tier 3 smoke is a safety net only.
3. **Every CRUD surface (create / edit / delete) has ≥1 real UI-driven test.**
4. **Every API mutation has ≥1 end-to-end test.**
5. **ESLint rule forbids `page.waitForTimeout` and `waitForLoadState('networkidle')`.**
6. **Zero admin-seeded "functional" tests.** At least one test per feature drives the UI from zero — no service-role bypass on the happy path.
7. **Cleanup in `afterEach` / `afterAll`.** No orphan data between runs.
8. **CI required check on `main` / `master`.** Branch protection enforces it.
9. **GitHub Action runs the full e2e suite on every PR**, blocks merge on failure.
10. **100% pass rate across 3 consecutive runs.** No flake.

## Tier definitions

- **Tier 1 — Real user journey.** Drives the UI, performs a real mutation, asserts persisted state.
- **Tier 2 — Navigation / visibility.** Loads a page or opens a modal, asserts elements visible, no mutation.
- **Tier 3 — Smoke / crash canary.** Single-assertion page-load test. Safety net only.

## Conventions
- Test directory: `tests/e2e/`
- Framework: Playwright 1.59 (chromium, mobile, tablet, android projects)
- Test environment: CI runs against a **localhost production build** (`npm run build && npm run start`) — matches PostHog/Supabase pattern of testing the same binary that ships. `BASE_URL` overrides for ad-hoc runs against a preview URL.
- Auth strategy: **globalSetup logs in once, persists `playwright/.auth/user.json`.** Authed specs import `test` from `tests/fixtures/base.ts` and use the `authenticatedPage` fixture (loads storageState — no per-test UI login).
- Data strategy: service-role Supabase client in `tests/helpers/api.ts`. `cleanupUserData(userId)` deletes child rows in FK-safe order (Supawright pattern). Tests that mutate should `afterEach` cleanup.
- Selector convention: `getByRole` / `getByText` / `data-testid` — never CSS classes. Legacy `#signup-email` on the login form is tracked in Upgrades.
- API client: `tests/helpers/api.ts` (`getServiceClient`, `requireServiceClient`, `cleanupUserData`, `seedSession`, `getTestUserId`).
- Auth helper: `tests/global-setup.ts` + `tests/fixtures/base.ts`.
- Fixtures: `tests/fixtures/base.ts` exports `test` with `authenticatedPage` fixture.

## Anti-patterns found
- **`page.waitForTimeout` — 11 occurrences** across `landing.spec.ts` (8), `payment.spec.ts` (3), `accessibility.spec.ts` (2), `visual/public-pages.spec.ts` (1). ESLint rule **landed** in `eslint.config.js` scoped to `tests/e2e/**`, currently set to `warn` so the existing 11 violations don't break CI — ratchet to `error` once the upgrade list is empty.
- **`waitForLoadState('networkidle')` — 1 occurrence** at `tests/e2e/visual/public-pages.spec.ts:26`. Flake factory; replace with explicit waits.
- **`page.route()` happy-path mocks — 5 sites** in `tests/e2e/dashboard-authed.spec.ts:87,102,112,124,129`. Test would pass with the entire backend down. Recategorize file as Tier 3 until rewritten.
- **`test.skip(!process.env.TEST_USER_EMAIL...)` — 30 occurrences** across 6 files. Silent skips hide a complete lack of authenticated coverage in CI.
- **`toBeVisible()` as only assertion after mutation — N/A** because no mutations are actually performed today.
- **`if (await el.isVisible()) { expect(el).toBeVisible() }` no-op pattern — 11 occurrences** in `tests/e2e/onboarding.spec.ts:54,67,82,96,110,124,143,158,174,191,193`. Test passes whether the element exists or not.
- **Class-based selectors** — `.mobile-nav-toggle`, `.skip-to-content`, `.particle-canvas` in `landing.spec.ts`, `accessibility.spec.ts`. Brittle to styling changes. Migrate to `data-testid` or `role` selectors.
- **CSS id selector `#signup-email` used for the login form's email field** — `auth.spec.ts:64`, `dashboard.spec.ts:11`, etc. Either rename the id to `#login-email` on the login page or use `getByRole("textbox", { name: /email/i })`.
